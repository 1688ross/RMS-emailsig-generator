Add it to Outlook

  1. Click Copy signature above.
  2. Open Outlook's signature settings (see your version below).
  3. Create a new signature, name it (e.g. "Ross Machinery"), click in the editor box and paste (Ctrl+V / ⌘V).
  4. Set it as the default for New messages and Replies/forwards, then Save.
  5. Send a test email to yourself and to a Gmail address to check it.

New Outlook / Outlook.com
